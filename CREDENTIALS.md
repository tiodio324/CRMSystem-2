# Учетные данные для входа в систему

## Роли пользователей

- **viewer** (Наблюдатель) - роль по умолчанию, только просмотр
- **manager** (Менеджер) - управление клиентами, сделками, задачами
- **admin** (Администратор) - полный доступ

## Пароли для входа

| Роль | Пароль |
|------|--------|
| Менеджер (manager) | `manager2026-crm` |
| Администратор (admin) | `admin2026-crm` |
