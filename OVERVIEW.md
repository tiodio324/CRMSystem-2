# Обзор проекта: CRM-система для малого бизнеса

## 📋 Описание проекта

Данное веб-приложение представляет собой CRM-систему (Customer Relationship Management) для управления взаимоотношениями с клиентами в малом бизнесе. Система разработана как Single Page Application (SPA) без использования `react-router`, что обеспечивает быструю навигацию между разделами без перезагрузки страницы.

**Основная цель проекта**: Автоматизация продаж и повышение эффективности работы с клиентами через ведение базы данных, управление сделками и задачами.

## 🎯 Основные возможности системы

### Для всех пользователей (включая неавторизованных):

1. **Просмотр базы клиентов**
   - Фильтрация по статусу (лид/потенциальный/клиент/неактивный)
   - Поиск по имени и контактам
   - Отображение информации о клиентах

2. **Просмотр сделок**
   - Воронка продаж
   - Фильтрация по этапам
   - Статистика по сделкам

3. **Просмотр задач**
   - Список задач с приоритетами
   - Фильтрация по статусу

### Для авторизованных пользователей (Менеджер):

1. **Управление клиентами**
   - Добавление новых клиентов
   - Редактирование информации
   - Изменение статуса клиента

2. **Управление сделками**
   - Создание новых сделок
   - Перемещение по этапам воронки
   - Редактирование сумм и условий

3. **Управление задачами**
   - Создание и редактирование задач
   - Назначение приоритетов
   - Отметка выполнения

### Для администраторов:

Все функции менеджера, плюс:

1. **Полное управление клиентами** (CRUD операции)
   - Деактивация клиентов
   - Массовые операции

2. **Управление сделками** (CRUD операции)
   - Удаление сделок
   - Полный доступ ко всем данным

3. **Управление задачами** (CRUD операции)
   - Назначение задач менеджерам
   - Контроль выполнения

- **ESLint** - линтер для проверки качества кода
- **TypeScript ESLint** - проверка типов TypeScript

## 🔐 Система ролей и прав доступа

### Роли пользователей:

1. **viewer** (Наблюдатель) - роль по умолчанию
   - Просмотр клиентов, сделок, задач
   - Нет возможности редактирования данных

2. **manager** (Менеджер) - требует авторизацию
   - Все права наблюдателя
   - Создание и редактирование клиентов
   - Управление сделками и задачами

3. **admin** (Администратор) - требует авторизацию
   - Все права менеджера
   - Управление всеми данными (CRUD)
   - Доступ к разделу "Администрирование"

**Пароли для входа** находятся в файле `CREDENTIALS.md`

## 🗄 Структура данных

### Основные сущности:

1. **Client (Клиент)**
   - id, name, email, phone
   - company, position
   - status (lead/prospect/customer/inactive)
   - source, notes, isActive

2. **Deal (Сделка)**
   - id, clientId, title
   - amount, stage
   - probability, expectedCloseDate
   - notes, isActive

3. **Task (Задача)**
   - id, title, description
   - clientId, dealId
   - priority, status
   - dueDate, assigneeId

4. **Contact (Контакт)**
   - id, clientId
   - type (call/email/meeting)
   - date, notes

## 📚 Что желательно понимать для защиты диплома

### Теоретическая часть:

1. **Что такое CRM?**
   - CRM (Customer Relationship Management) - система управления взаимоотношениями с клиентами
   - Позволяет отслеживать все контакты с клиентами, управлять продажами

2. **Воронка продаж**
   - Этапы: Новая → Переговоры → Предложение → Выиграна/Проиграна
   - Визуализация процесса продаж

3. **SPA (Single Page Application)**
   - Приложение загружается один раз, переходы без перезагрузки
   - Навигация через MobX store

4. **Firebase Realtime Database**
   - Облачная NoSQL база данных
   - Синхронизация в реальном времени

### Возможные вопросы:

1. **"Почему выбрана CRM для малого бизнеса?"**
   - Простота использования

2. **"Как работает воронка продаж?"**

   - Каждый этап имеет свою вероятность закрытия
